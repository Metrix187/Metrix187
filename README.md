# Metrix187

I build local-first privacy tools, embedded systems, and computation in places computation has no business being.

---

## Projects

**[narcan.delivery](https://github.com/Metrix187/narcan.delivery)** — free, plain-English guide to naloxone access by US state. A [Quantara Innovations](https://quantara.cv) project.

**[metadetect](https://github.com/Metrix187/metadetect)** — detect Meta Ray-Ban glasses and nearby Bluetooth recording devices before they detect you. Web app + ESP32 firmware.

**[qwennie](https://github.com/Metrix187/qwennie)** — 78k-parameter transformer running entirely in CSS. RoPE, RMSNorm, SwiGLU, int8 matmuls, and a KV cache built from custom properties. No JavaScript.

**[pawtraced](https://github.com/Metrix187/pawtraced)** — a full ray tracer in pure CSS. Every pixel is an identical empty `<div>`; the stylesheet is the shader. Shadows, reflections, animated sun. No JavaScript.

**[ESP32-CYD-Weather-Station](https://github.com/Metrix187/ESP32-CYD-Weather-Station)** — touch-enabled weather station on the ESP32 Cheap Yellow Display. OpenWeatherMap integration, custom SD card backgrounds, on-screen keyboard.

**[esp32-p4-h264-benchmark](https://github.com/Metrix187/esp32-p4-h264-benchmark)** — hardware H.264 encoding benchmark on the ESP32-P4. 1080p25, ~34.7ms avg encode latency on rev 3.1 silicon.
